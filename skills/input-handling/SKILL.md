# Input handling

- Support every input the targets have: tap-tap and swipe on touch,
  click and drag on mouse, focus navigation on keyboard and gamepad.
- Convert input to game actions in one place; the game decides
  legality, the view plays the response.
- Generous hit areas on touch; never require precision the screen size
  can't give.
